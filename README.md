# English Hanon Speaking Log

This repository is used to track my daily English speaking practice using the book *Eigo no Hanon*.

## Structure

- `logs/`: Contains daily logs written in Markdown format.
- `templates/`: Contains reusable templates.

## Usage

Each day, copy the template in `templates/daily-log-template.md` to a new file in `logs/` using the current date as the filename (e.g., `2025-04-30.md`). Fill in your log, commit, and push to GitHub.

Happy studying! ✍️📘
